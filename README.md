# ASAC Voice Chatbot 🤖🎤

ASAC is a voice-based AI chatbot developed as part of my technical training project.

## About the Project

The project allows the user to communicate with the chatbot using voice input. The user's speech is converted into text, sent to the backend, and processed using an AI API. The chatbot then returns a response that is displayed in the chat interface and can also be read aloud.

## Features

- 🎤 Voice input
- 💬 Interactive chat interface
- 🤖 AI-generated responses
- 🔊 Text-to-speech responses
- 🌐 Arabic and English language support
- 📱 Responsive design
- 🎀 Simple and modern user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- Speech Recognition API
- Speech Synthesis API
- AI API
